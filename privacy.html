1. 我们是谁

「米果」是由米果智能（个人开发者）运营的语音/对话类应用。本政策说明我们如何收集、使用、存储与保护您的个人信息，以及您享有的权利。

2. 我们收集哪些信息

我们仅在提供服务所必需的范围内处理信息，主要包括：

  • 账号标识：您用于登录的电子邮箱地址。
  • 验证与鉴权信息：邮箱验证码发送与校验记录；登录成功后由服务端签发的访问令牌（例如以 nm_ 开头的令牌）。令牌用于后续接口鉴权，应用不会把生产环境 API Key 固化进安装包。
  • 对话与会话内容：您在主会话中发送的文本/语音相关请求，以及为完成回复所必需的上下文。
  • 设备与日志信息：设备型号、操作系统版本、应用版本、崩溃与诊断日志、粗略网络状态等，用于保障安全、排查故障与改进稳定性。
  • 本地存储：登录状态、偏好设置等可能保存在设备本地安全存储中。

我们不会在安装包中预置可用于冒充您身份的生产密钥；聊天请求使用登录后获得的令牌进行鉴权。

3. 我们如何使用信息

  • 完成邮箱验证码登录、会话保持、退出与重新登录；
  • 提供主会话对话、历史与相关功能；
  • 保障服务安全（防滥用、排查故障、审计必要日志）；
  • 履行法律法规要求，或响应您依法提出的请求（如查阅、更正、注销）。

我们不会将您的个人信息出售给第三方。若未来因合规或功能需要引入处理者，将在本政策中更新说明。

4. 存储地点与期限

服务部署与接口访问地址以应用当前配置的公网服务为准（含鉴权与对话相关接口）。我们在实现服务目的所必需的最短期限内保留信息；账号注销或您依法请求删除后，将在合理期限内删除或匿名化，法律法规另有规定的除外。

5. 信息共享与委托处理

除下列情形外，我们不会与第三方共享可识别您身份的个人信息：

  • 获得您的明确同意；
  • 为提供服务所必需的基础设施或模型能力供应商（其仅在委托范围内处理）；
  • 法律法规规定、司法机关或行政机关依法提出的要求。

6. 您的权利

  • 访问与更正：可通过应用内账号相关入口查看或更新可编辑信息。
  • 注销账号：可在应用「设置 / 合规与关于 / 注销账号」发起注销；已登录时将按服务端注销流程处理，未登录时可按应用内指引提交申请并联系我们。
  • 撤回同意与意见反馈：可通过下方联系方式与我们联系。

7. 未成年人

本应用主要面向成年人。若您为未成年人，请在监护人指导下阅读本政策并使用本服务。我们不会故意收集儿童的个人信息。

8. 安全措施

我们采取合理的技术与管理措施保护个人信息，包括传输加密（HTTPS）、访问控制、最小权限与密钥不进包等。但请理解，任何互联网传输与存储都无法保证绝对安全。

9. 开源与第三方说明

米果客户端按 GPL-3.0-or-later 开源意向发布；源码仓库地址见应用内「开源 / 源码」入口（GitHub）。开源仓库不含您的个人账号数据。若产品集成第三方开源组件，其许可证以对应声明为准。

10. 政策更新

我们可能适时更新本政策。重大变更将通过应用内提示或本页更新日期予以告知。请以本页最新版本为准。
